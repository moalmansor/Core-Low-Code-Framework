# ADR-0016: Phase numbering follows the specification

- Status: Accepted (owner confirmed on the Phase 0 PR, 2026-10-02)
- Date: 2026-10-02

## Context

CLAUDE.md says work is delivered in seven phases (0–6). Specification §8.1 defines eight, including Phase 2.5 (Pilot & Validation).

## Decision

Follow the specification: eight phases, 0, 1, 2, 2.5, 3, 4, 5, 6. Phase 2.5 uses the branch `phase-2-5-pilot` (confirmed by the owner). The owner will update CLAUDE.md.

## Consequences

The specification is the contract and wins over other documents (CLAUDE.md, "It wins over any assumption"). CLAUDE.md is updated by the owner.
