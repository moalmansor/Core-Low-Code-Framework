# ADR-0005: Enumerations stored as strings with CHECK constraints

- Status: Accepted (Phase 0, pending owner review)
- Date: 2026-10-02

## Context

MySQL `ENUM` has no SQL Server equivalent, and enum lists change between phases.

## Decision

Enumerated columns are `VARCHAR/NVARCHAR(32)` backed by PHP backed enums, with CHECK constraints generated by the driver layer.

## Consequences

This is portable, readable, and extensible through a migration that only changes a CHECK constraint.
